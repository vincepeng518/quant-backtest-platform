# 突破策略雙時間級別搜尋（Stage 6–11，2026-09-20）

## 任務
找兩個不同時間級別、**樣本外正期望值**的突破策略。

## 結論：**沒找到 —— 兩個時間級別在樣本外都無法證明正期望值**

| 級別 | 開發期表現 | 樣本外表現 | 判定 |
|---|---|---|---|
| **4h** | IS 中位 Sharpe **+1.16**（100% 標的正） | TEST 中位 **+0.06**（57% 標的正，衰減到零） | ✗ 衰減 |
| **1h** | IS 中位 Sharpe +0.70（100% 正） | TEST 中位 **−2.35**（12% 標的正） | ✗ 崩掉 |

## 本輪最重要的新發現：**出場方法是關鍵維度**

前幾輪（`research/breakout_jev/` 十階段 + `breakout_jev2` Stage 1–5）**只測過固定 ATR 停損/停利（OCO）一種出場**。
那是趨勢跟隨的結構性錯誤 —— 固定停利把大趨勢砍在半路，而趨勢跟隨的獲利本來就來自少數極端獲利單。

改成 **唐奇安出場**（收盤跌破前 N 根最低）或 **移動停損** 後，4h 突破的樣本內表現**戲劇性改變**：

| 出場方法 | 4h IS 中位 Sharpe | 4h IS 平均每筆 |
|---|---|---|
| OCO（舊做法） | 約 0.0 | 約 −0.25% |
| **唐奇安（96，both）** | **+1.16** | **+9.65%** |
| 移動停損（192） | +0.90 | +0.67% |

**但樣本外全部失效。** 這是「找到了正確的機制，但它沒有可持續的 alpha」——兩件事不矛盾。

## 逐年表現揭露了 regime 依賴（Stage 8）

4h 唐奇安突破，參數 `(96, both, donchian, 4.0, 3.0, 96)`：

| 年 | 各標的平均% | 正標的 |
|---|---|---|
| 2018 | +1.43 | 50% |
| 2019 | **+6.91** | 100% |
| 2020 | **+13.24** | 100% |
| 2021 | **+14.85** | 100% |
| 2022 | −0.53 | 29% |
| 2023 | +3.19 | 71% |
| 2024 | **+7.36** | 100% |
| 2025 | **−1.66** | 14% |
| 2026 | +2.31 | 86% |

**這是趨勢跟隨的典型長相（不是隨機雜訊）**：趨勢年大賺（2019-2021、2024），盤整/熊年虧（2022、2025）。
有經濟意義，但**無法事先判斷**哪一年是哪一種 → 不能交易。

## 嘗試過的 regime 過濾器（Stage 9）——也失敗

只在前段開發、留出段只測一次：

| 策略 | 開發期 | 留出期 |
|---|---|---|
| 4h + EMA200 趨勢過濾 | 中位 Sharpe +0.87（**100% 標的正**） | 中位 **+0.18**（57% 正） |
| 4h + 波動率百分位過濾 | +0.81（100% 正） | 未通過候選篩選 |
| 1h 無過濾 | +0.70（100% 正） | 中位 **−0.88**（25% 正） |

**開發期 100% 標的為正、留出期全崩 = 過擬合的標準長相。**

## 誠實檢定：Stage 10 的那個「顯著」是假象（Stage 11）

Stage 10 用 182 個 okx 標的做橫斷面 bootstrap，得到唯一存活候選：

```
trail_both_lb192:  留出平均 +0.5556%  正標的 58%  bootstrap p=0.0254  → 看起來顯著
```

**三項修正檢定把它證偽：**

| 檢定 | 結果 | 判定 |
|---|---|---|
| A 時間分塊一致性（4 段） | 4/4 段為正 | 通過 |
| B 標的集中度 | 前 10 檔貢獻 **61%** 獲利 | ✗ 不是普遍 edge |
| C 相關性修正 | ρ=0.077 → 名目 182 檔的**有效獨立樣本僅 12.2** | ✗ |

**關鍵計算：**

```
名目 t=2.06   p=0.0203        ← 表面顯著
修正 t=0.53   p_eff=0.3022    ← 真實
Bonferroni 門檻（5 配置）= 0.0100 → 不通過
```

**教訓（最重要的方法論收穫）**：
> 標的間平均相關只有 ρ=0.077 看起來微不足道，但 `n_eff = N/(1+(N−1)ρ)` 下，
> 182 檔只剩 12.2 個獨立樣本。**用橫斷面標的數當樣本量做 bootstrap，在相關性資產上會系統性高估顯著性。**

這是 Stage 10 差點給出假正面結論的原因。若沒做 Stage 11，就會交付一個不存在的 edge。

## 已知缺口（不可假裝有）

- 1h 樣本僅 443 天 / 8 檔，統計力不足；1h 的失敗比 4h 更不可靠
- 未計入資金費率（perp 持倉成本）
- 滑價固定 0.02%/邊；低流動性標的實際更差
- 4h 留出期只有 2 年（2024-2026），涵蓋的 regime 種類有限
